# Documentation map

- `design/`: metadata-free conversions of the original business and technical
  design documents.
- `planning/`: roadmap, backlog, Definition of Done, risks, and controlled lists
  converted from the original workbook.
- `adr/`: active architectural decisions. ADRs override older design snapshots
  when the two conflict.
- `specifications/`: executable contracts for targets, backtesting, APIs, and
  operational behavior.
- `source/`: local-only Office artifacts; ignored by Git except for its README.
