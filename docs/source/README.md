# Local Office sources

This directory is reserved for the original Office artifacts used to bootstrap
MarketPulse:

- `MarketPulse_Diseno_Negocio.docx`
- `MarketPulse_Diseno_Tecnico.docx`
- `MarketPulse_Backlog.xlsx`

The binaries and their embedded metadata are intentionally ignored by Git. Only
their metadata-free Markdown conversions under `docs/design/` and
`docs/planning/` may be published.

When a local source changes, regenerate its Markdown counterpart and review the
resulting textual diff before committing it.
